## Featured Projects

<details>
<summary><strong>Kinetic Scholar</strong> · Study planning, a focus timer, and session history</summary>

<br />

A local study workspace for organising subjects, planning around the time available, and keeping track of completed sessions.

| Area | Details |
| :--- | :--- |
| **Stack** | Python, Flask, Waitress, SQLite, JavaScript |
| **Scope** | A single-user workspace supporting up to 20 active subjects |
| **Reliability** | The timer recovers after a reload. Request IDs prevent a retried save from creating duplicate sessions. |
| **Data handling** | Local persistence, a loopback-only server, and CSV exports with formula protection |
| **Reporting** | Daily and weekly study time, streaks, focus ratings, and planned versus actual allocation |
| **Repository** | [itsmeshruti1/kinetic-scholar](https://github.com/itsmeshruti1/kinetic-scholar) |

SQLite holds saved sessions and plans, while the browser keeps unfinished timer state. That separation lets a user return to an interrupted session and save it when they're done.

</details>

<details>
<summary><strong>Tracify</strong> · Road incident maps and hotspot analysis</summary>

<br />

A dashboard for exploring road incidents on a map and finding clusters with DBSCAN. The demo uses synthetic Bengaluru data.

| Area | Details |
| :--- | :--- |
| **Stack** | React, TypeScript, Vite, Leaflet, IndexedDB, Firebase |
| **Dataset** | 175 synthetic observations in the demo, with a limit of 2,000 records per workspace |
| **Analysis** | Geographic clustering using haversine distances, with date and severity filters |
| **Data handling** | Local persistence, optional authenticated cloud storage, validated CSV imports, and formula-safe exports |
| **Reporting** | Ranked hotspots, source incidents, risk factors, and incident reports with media attachments |
| **Repository** | [itsmeshruti1/Tracify](https://github.com/itsmeshruti1/Tracify) |

Each hotspot can be traced back to its source incidents and scoring factors, so users can inspect what contributed to a ranking.

</details>
